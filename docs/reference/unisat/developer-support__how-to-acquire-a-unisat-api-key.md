# How to Acquire a UniSat API Key

Previously, API keys were requested by contacting the UniSat team and applying via email. With the new Developer Center, you will need to register with your email and choose the appropriate plan.

Here are the steps to acquire a UniSat API Key:

* Visit [UniSat website](https://unisat.io/) and click '🌐' in the homepage navigation bar. From the dropdown menu, select 'API Service' to access the detailed API plans page. Alternatively, you can directly click [here](https://unisat.io/plans) to view the API plans.

* Choose the plan that suits your needs and click '**Get Started**' under the detailed description of the plan to go to the Developer Center plan acquire page. Or you can click <https://developer.unisat.io/plan> to enter the Developer Center, or click on&#x20;

> Enjoy 50% off when you choose Specialist or Enterprise CLI & MCP limited-time plans
>
> Enjoy 20% off when you choose Specialist or Enterprise Base limited-time plans

* Before acquiring a plan, you need to register a Developer Center account using your email.

<figure><img src="https://3523236551-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FJ4NHAHIVnWQiEecvs1By%2Fuploads%2FBlkwVnfSxnSD4tZOWYtX%2F20240716-205021.png?alt=media&amp;token=40744b9b-b4e3-49d0-bb93-9f5905579447" alt=""><figcaption></figcaption></figure>

* Once registered, go to the Dashboard page where you will see your API Key current API Key configuration, and your API Request Log.&#x20;
  * For newly registered accounts, we offer developers a free access quota of 5 calls/second, 1,000 calls/day on Bitcoin&#x20;
  * Plans for Fractal Bitcoin are free to use.&#x20;
  * API Keys for Bitcoin and Fractal are separate and cannot be used interchangeably. You'll need to apply for a Bitcoin API Key and a Fractal API Key separately.

<figure><img src="https://3523236551-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FJ4NHAHIVnWQiEecvs1By%2Fuploads%2FUFBVf4qCjBy5y4HZwvvU%2F9.png?alt=media&amp;token=59ead6f1-eca6-47b7-ac34-57bbcb4cbba2" alt=""><figcaption></figcaption></figure>

If you exceed the current usage limit, you can upgrade your API quota.&#x20;

How do I upgrade my API plan?​​

* Click **"Upgrade Plan"** on the right side of your dashboard, or
* Click **"Plan – Bitcoin Mainnet"** in the upper-left corner to open the API plan selection page and choose a higher-tier plan.

<figure><img src="https://3523236551-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FJ4NHAHIVnWQiEecvs1By%2Fuploads%2F4BhKL4y9Am001EgL3t4Y%2F11.png?alt=media&amp;token=7336e8a0-7237-4f7d-9a79-b332e67badcc" alt=""><figcaption></figcaption></figure>

* Choose the plan you need and click the '**Buy**' button under the specific plan to enter the acquire page.

<figure><img src="https://3523236551-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FJ4NHAHIVnWQiEecvs1By%2Fuploads%2FSPlQ7XFtzuzrfOpYy3qG%2F12.png?alt=media&amp;token=76a6bbd6-64ce-4f00-ba1c-d94fbf5539e8" alt=""><figcaption></figcaption></figure>

* Payments are currently accepted via PayPal, BTC, and USDT(ETH & TRON).

Here is an example of a BTC payment method, click '**Pay with BTC**', then select '**Pay with Wallet**'. The page will prompt you to sign; confirm the input and output information carefully, and click 'Sign & Pay' to complete the acquire.
